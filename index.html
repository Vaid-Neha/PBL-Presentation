Problem Statement

Deepfakes are AI-generated synthetic media created using GANs and diffusion models. They pose threats such as misinformation, identity theft, and cybercrime. Traditional detection systems fail against modern high-quality deepfakes.

Literature Review

  • • CNN (XceptionNet): High accuracy (~97%) but poor generalization
  • • LSTM Models: Capture temporal features (~91%)
  • • Transformers: Good generalization but heavy computation
  • • SyncNet: Audio-visual sync detection but limited scope

Research Gap

  • • No audio-visual consistency scoring
  • • Lack of explainability
  • • Poor performance on compressed data
  • • No unified multimodal model

Proposed Model – AVXF-Net

A multimodal AI model combining CNN (visual), Bi-LSTM (temporal), and audio CNN with cross-modal attention to compute an Audio-Visual Consistency Score. Includes explainable AI outputs.

Implementation Plan

Step 1: Data Preparation

Dataset collection, frame extraction, audio extraction

Step 2: Feature Extraction

CNN (visual), LSTM (temporal), MFCC (audio)

Step 3: Model Development

Cross-modal attention + fusion model

Step 4: Explainability

Grad-CAM + SHAP integration

Step 5: Evaluation

Cross-dataset + compression testing

Step 6: Deployment (Future)

Streamlit interface for detection

Expected Results

The model is expected to achieve ~95% accuracy with improved robustness, real-time detection, and explainable outputs.
